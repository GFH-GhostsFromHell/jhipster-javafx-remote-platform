This repository now contains a deployable `portal/` Spring Boot starter plus the original JHipster JDL. The Render Dockerfile should build `portal/` directly with Maven. The admin portal supports per-user feature overrides and client configuration, while `/api/public/client-health` is available before sign-in and authenticated `/api/client/status` + `/api/client/bootstrap` support the JavaFX client after sign-in.
