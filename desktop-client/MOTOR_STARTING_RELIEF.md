# Motor failed-start OCPD option

The Section 28 AC and DC motor branch worksheets include an optional **Motor fails to start** checkbox.

Normal branch OCPD selection uses the standard Table 13 rating not exceeding the Table 29 calculated maximum. When the checkbox is selected, the calculator tests the next standard OCPD size against the applicable CEC 2024 Rule 28-200(4) failed-start ceiling for time-delay fuses, non-time-delay fuses, or inverse-time circuit breakers. Instantaneous-trip protection remains on the Rule 28-210 calculation path.
