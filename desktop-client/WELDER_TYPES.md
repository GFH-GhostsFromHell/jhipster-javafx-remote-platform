# Section 42 welder categories

The Electrical Workbench Section 42 single-welder calculator exposes the three CEC 2024 calculation categories separately:

- Transformer / inverter arc welder — Table 42A duty-cycle factors.
- Motor-generator arc welder — Table 42B duty-cycle factors, with motor protection/control handled through the applicable Section 28 path.
- Resistance welder — Table 42C duty-cycle factors.

This note also ensures changes to the Section 42 calculator go through the normal Windows desktop packaging/release pipeline.
