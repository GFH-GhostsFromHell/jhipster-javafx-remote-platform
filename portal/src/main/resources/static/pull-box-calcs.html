Size a pull box in the field.

Choose the pull arrangement, add every conduit by entry wall, and read the minimum dimensions with worked formulas. The worksheet follows the applicable geometry in CEC 2024 Rule 12-3036 for insulated conductors No. 4 AWG or larger.

1. Select the pull

Conduit sizes are Canadian trade-size designations (mm), not actual measured conduit outside diameters.

2. Add entries

Visual arrangement

Front view: left, right, top and bottom entries. Back-wall entries point toward the removable front cover (side-view depth test). Drawing is a layout guide and is not dimensioned to scale.

Important field checks

Check the edge-to-edge separation for entries containing the same insulated conductor (six times the larger entry trade size). Confirm room for bushings, locknuts, conductor bend radius, supports and pulling access. A minimum from this rule is not automatically a complete box specification.
