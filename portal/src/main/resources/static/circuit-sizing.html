Before installation

This calculator never certifies compliance or automatically picks an AWG size from unverified data. Confirm the Ontario Electrical Safety Code edition/amendments, actual terminal marking, conductor material and dimensions, CEC Table 1–4, Table 5A/5C, neutral count, wiring method, overcurrent protection, and upstream voltage drop. Any specialty circuit requires its own applicable Code path.
