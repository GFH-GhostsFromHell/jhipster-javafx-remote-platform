How verification is completed

A qualified reviewer compares each used value with an authorized CSA C22.1:24/OESC copy, records the edition, table, conditions, source revision, reviewer and date, then checks regression cases and platform behavior. Numerical data must not be promoted to verified status without that evidence. The app does not republish proprietary code tables.
