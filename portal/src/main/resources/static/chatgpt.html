Hosted ChatGPT setup

The web workspace is installed, but OpenAI website authorization is not active yet.

Unlike the locally installed desktop and Android apps, a remotely hosted website cannot use OpenAI's dynamic open-source loopback registration. The portal needs an OpenAI-issued website OAuth client and, for ChatGPT-plan usage, plan-sharing approval for that client.

Once those deployment credentials are configured, this same page activates account connection, model selection and in-portal chat automatically.
