Bender calibration

Measure your own shoe on scrap conduit. Save a separate profile for each bender, conduit type and trade size. No manufacturer deduct or gain is assumed.

1 · Bender profile

Saved locally first. When signed in, profiles sync to your Electrical Workbench account. Conflicting edits are backed up for review.

2 · Calibrate stub-up deduct

Make a 90° test stub. Measure the actual finished stub and the original arrow mark distance from the same square stock end and specified reference surfaces.

Effective deduct = finished stub height − distance to arrow mark. Use the same measurement convention each time.
Enter the two measurements above.

3 · Calibrate 90° bend gain

Bend a straight test piece through 90°. Measure its two finished legs consistently to the back-of-bend reference used for the cut-length calculator.

Gain = finished leg A + finished leg B − original stock. Gain is not the stub arrow deduct.
Enter three test-piece measurements above.

4 · Check angle and apply calibration

Angle check is optional.

After saving, open the Stub-up, Kicked 90°, Back-to-back 90°, or Bend Gain tool and select Use saved calibration. Calibration belongs to the recorded bender/size/material only. Check springback, radius, minimum stub, bends between pull points and manufacturer instructions on the job.
