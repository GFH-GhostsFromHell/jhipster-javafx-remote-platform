Recovery and owner controls

Important: Your ability to recover your computer must never depend exclusively on this portal. Use your operating system's supported recovery process, keep an independently accessible copy of the recovery key, and confirm backups before making any encryption changes.

The desktop app can create a separately encrypted copy of a manually chosen file with AES-256-GCM. The owner saves an offline recovery key and can decrypt independently. This portal does not issue remote encryption, device locking or key-extraction commands. Optional cloud escrow stores only a separate, password-wrapped recovery backup. The owner retains an independent offline key.

Encrypted recovery-key backups

A desktop owner may optionally back up a recovery code wrapped with a separate strong passphrase. The portal stores encrypted ciphertext only. Operator approval permits a one-time retrieval for 15 minutes; the owner unwraps it locally and may recover independently using the offline key.

Operator approvals

Approval grants the owner one retrieval of encrypted recovery material, not access to the computer or the plaintext recovery key.

Encrypted support chat

Messages are encrypted in your browser or desktop application using AES-256-GCM and a shared passphrase. The portal stores ciphertext only. Share the passphrase with your operator via an independent trusted channel, not in this chat. This is a first-version passphrase protocol, not an audited enterprise messenger.

Current role: Checking…. Chat messages are loaded when you press Refresh; there are no push notifications.

Enter the shared passphrase and refresh to read messages.

Operator recovery review

An approval is a tracked support decision, not a decryption command. The owner always retains independent offline recovery.
